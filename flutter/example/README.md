# GlobalDS Flutter component catalog

A runnable catalog of eight new core controls and six improved components,
using `package:global_ds/global_ds.dart`. Select a component to inspect its
states. Composed forms, editors and dialogs are deferred as future patterns.

```sh
flutter pub get
flutter run -d chrome
```

`flutter test` runs the standalone smoke test. The parent package suite checks
all 14 specimens at 320 and 1000 logical pixels. See
`../docs/flutter-components.md` for the component list and API ownership.
